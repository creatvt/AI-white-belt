# AI White Belt landing page

Static website. No build step required.

## Run locally

From this directory, run `python3 -m http.server 8000`, then open http://localhost:8000.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload all these files to the repository root and commit them.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, then main and / (root).
5. Save and use the URL GitHub displays once deployment completes.

The form is a demonstration: it does not submit or store email addresses. Replace sample testimonials and lesson titles, complete the privacy notice, and connect the form before collecting registrations.
